## Обновление каталога

```sh
python -m pip install -r curriculum/requirements.txt
python -m unittest discover -s curriculum/tests -v
python curriculum/sync.py --workers 4 --parse-workers 2
python curriculum/verify.py
```

Источник — официальный раздел образовательных программ РТУ МИРЭА: https://www.mirea.ru/sveden/education/eduop/. Каталог обходится целиком, включая все опубликованные годы набора, уровни и формы обучения. Ссылки на электронные подписи и заглушки документов исключаются.

`curriculum/data/manifest.json` содержит число планов и дисциплин, распределение качества, SHA-256 HTML каталога и список частей импорта. Каждая часть — UTF-8 JSON размером не более 900 000 байт и не более 200 планов с собственным SHA-256, числом планов и именем, включающим хеш содержимого. Манифест переключается только после записи всех частей.

Побайтовые дубликаты с одинаковыми направлением, профилем, уровнем, формой и годом объединяются; дополнительные URL сохраняются в `source_variants`. `source_document_count` отражает число опубликованных документов до такого объединения, без записей с отсутствующим учебным планом.

Полный JSON, SQL для `public.learning_roadmap_import(jsonb)` и отчёт выполнения сохраняются в `curriculum/public/`; они не включаются в Git. Сырые PDF и проверяемые по хешу результаты разбора хранятся в `curriculum/.cache/`.

## Контракт данных

План содержит стабильный `id`, направление `title` и `program_code`, профиль `profile`, уровень `level`, форму `study_form`, год `admission_year`, институт `institute`, исходный URL, SHA-256 документа, время успешной загрузки `checked_at`, время разбора `parsed_at`, версию парсера, качество, предупреждения, семестры и дисциплины.

`complete` означает успешно прочитанную семестровую таблицу без выявленных несоответствий. `partial` означает извлечённые дисциплины с отсутствующими или неоднозначными данными. `unavailable` означает, что надёжно извлечь дисциплины не удалось. Отсутствующие коды дисциплин, часы, зачётные единицы и семестры передаются как `null`.

Сумма зачётных единиц сверяется с итогами блоков исходного плана. Если опубликованы только контактные часы по семестрам, полный объём вычисляется из зачётных единиц исключительно при совпадении общего объёма документа с 36 часами на зачётную единицу. Такие строки содержат `hours_basis=document_credit_ratio` и предупреждение; в остальных неоднозначных случаях часы остаются `null`.

Одна дисциплина, читаемая несколько семестров, имеет отдельные строки `id`, общий `subject_id` и номера семестров. Буквенные обозначения A–F из учебного плана соответствуют семестрам 10–15. Формы контроля передаются как `exam`, `credit`, `graded_credit`, `course_project`, `course_work`.

`choice_group` связывает альтернативы в блоке выбора. Такой блок может быть обязательным. `is_optional` обозначает факультатив, а `kind=elective` сохраняет принадлежность к факультативному разделу. Семестровая нагрузка исключает факультативы и учитывает одну альтернативу каждого блока. Выбор конкретной альтернативы хранится отдельно в личной траектории.

Для таблиц СПО без опубликованного распределения по семестрам сохраняются общий объём дисциплины, её код и исходные обозначения контроля в `raw_control_forms`. Номер семестра не выводится из номера итоговой аттестации.

## Сбои и ограничения

Запросы разрешены только по HTTPS к `mirea.ru` и `www.mirea.ru`; проверяется и каждый редирект. Действуют ограничения размеров, числа страниц, соединений, повторов и времени ожидания. Ответы кэшируются на 24 часа; сам HTML каталога обновляется при каждом сетевом запуске. `checked_at` остаётся временем фактической успешной загрузки при использовании кеша.

Каталог меньше 100 записей, сокращение более чем на 15% или ошибки скачивания более 20% документов завершают команду кодом 2 и сохраняют ранее опубликованные данные. Сбой отдельного документа, ухудшение качества и потеря более 20% ранее извлечённых строк сохраняют последний успешный разбор с `source_stale=true` и временем новой попытки. Отсутствующие в новом каталоге программы не удаляются автоматически из базы.

Разбор использует текст и геометрию исходного PDF. Изображения без текстового слоя и неподдержанные структуры остаются явно недоступными. PDFium запускается в ограниченном числе отдельных процессов. Фикстуры тестов содержат извлечённые ячейки реальных планов 2026 года, URL и хеш исходного PDF.

```sh
python curriculum/sync.py --offline --output curriculum/scratch/preview-data --public curriculum/scratch/preview-public
```

Команда выше повторно разбирает только локальный кеш. Она предназначена для проверки парсера и не подтверждает доступность источника в сети.

## Сетевой маршрут GitHub Actions

Сайт МИРЭА возвращает географическую блокировку для GitHub runners. Обновление поддерживает отдельную функцию `learning-source-relay` в российском регионе Yandex Cloud. Адрес функции задаётся непарольной переменной репозитория `MIREA_SOURCE_RELAY_URL`, её служебный токен — секретом `MIREA_SOURCE_RELAY_TOKEN`. Токен разрешает только получение публичных учебных планов и не даёт доступа к GitHub, Supabase или облачному аккаунту.

`relay.py` принимает авторизованные GET-запросы только к официальному HTML каталога и PDF в наблюдаемом каталоге `/<32 hex>/sveden/files/`. Произвольные сайты, другие пути, параметры исходного URL и перенаправления к ним запрещены. Неавторизованный запрос завершается до обращения к источнику.

Исходные 64 МиБ HTML или 32 МиБ PDF сжимаются gzip и передаются частями до 2 МиБ в JSON/base64. Клиент проверяет исходный URL, время сетевой проверки, размеры, последовательность частей и SHA-256 каждой части и документа. Это учитывает [лимит HTTP-ответа Cloud Functions](https://yandex.cloud/en/docs/functions/concepts/function): 3,5 МБ. При изменении документа между частями обновление прерывается, предыдущая публикация сохраняется.

Кеш функции ограничен 96 МиБ и 240 секундами; ежедневный сбор действительно обращается к источнику. На экземпляр разрешено не более четырёх одновременных запросов и 120 запросов в минуту. Ограничения масштабирования: два экземпляра и четыре запроса в каждой зоне, без постоянно подготовленных экземпляров. Функция использует 512 МБ памяти, время выполнения ограничено 60 секундами. Локальный компьютер или туннель для работы не требуются.

Развёртывание выполняется в уже настроенном облачном каталоге:

```sh
python curriculum/deploy_relay.py --folder-id YOUR_EXISTING_FOLDER --profile default --repository 0niel/mirea-miniapps-demo
```

Команда создаёт или обновляет только `learning-source-relay`, меняет её служебный токен, проверяет реальный каталог и отказ без токена, затем записывает настройки GitHub Actions. Токен не сохраняется в файлах проекта и не выводится. Публичный адрес, версия функции, размер и SHA-256 проверенного источника сохраняются в локальном `curriculum/public/relay-deployment.json`. В данных приложений источником всегда остаётся официальный URL МИРЭА.
